# Taller: botón alert con controlador de eventos

Recordatorio teórico: En JavaScript, un evento es una acción que ocurre en la página web, como un clic, un movimiento del ratón o una pulsación de tecla. El navegador nos permite "escuchar" estos eventos y ejecutar código en respuesta. El método clave para esto es addEventListener, que se aplica sobre un elemento del DOM. Su sintaxis básica es: elemento.addEventListener('tipoDeEvento', funcionManejadora). El primer argumento es el nombre del evento como cadena de texto (por ejemplo 'click'), y el segundo es la función que se ejecutará cuando ese evento suceda. Esta función se llama controlador o manejador de eventos (event handler). El modelo mental correcto es: primero seleccionas un elemento (con document.getElementById, document.querySelector, etc.), luego le "enganchas" un oyente que espera pacientemente hasta que ocurra la acción, y finalmente defines qué debe pasar. La función alert() muestra una ventana emergente con un mensaje al usuario. Errores frecuentes: escribir 'onclick' en lugar de 'click' dentro de addEventListener; poner paréntesis en la función manejadora (funcion() en vez de funcion), lo que ejecuta la función inmediatamente en lugar de esperar el evento; e intentar seleccionar un elemento antes de que el DOM esté cargado. Mini-ejemplo: const boton = document.getElementById('miBoton'); boton.addEventListener('click', function() { alert('¡Hiciste clic!'); }); Con estas bases, ya puedes conectar la interacción del usuario con la lógica de tu programa. Enunciado del taller: Tu objetivo es construir una pequeña página web interactiva que muestre un mensaje mediante alert() cuando el usuario haga clic en un botón. Este ejercicio consolida la unión entre HTML, JavaScript...
