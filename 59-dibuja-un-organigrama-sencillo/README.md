# Dibuja un organigrama sencillo

**Recordatorio teórico** Un organigrama (o diagrama de flujo) es una representación visual de un algoritmo. Permite mostrar gráficamente la secuencia de pasos que sigue un programa, facilitando su comprensión antes de escribir una sola línea de código. En los capítulos anteriores trabajaste con pseudocódigo y secuencias de instrucciones: el organigrama es el paso natural siguiente, porque convierte esas instrucciones en una imagen estructurada. Los elementos fundamentales de un organigrama son: el **óvalo** (inicio y fin del proceso), el **rectángulo** (acción o instrucción), el **rombo** (decisión: bifurcación con dos salidas, Sí/No o Verdadero/Falso), el **paralelogramo** (entrada o salida de datos) y las **flechas** (flujo de ejecución). Un error frecuente en principiantes es confundir una acción con una decisión, o dibujar flechas sin sentido claro. Otro error habitual es olvidar el símbolo de inicio o de fin, dejando el diagrama «abierto». Mini-ejemplo: imagina un algoritmo que pregunta si hace frío. Si la respuesta es Sí, el usuario se pone el abrigo; si es No, sale directamente. Este proceso sencillo ya contiene los tres elementos esenciales: una entrada (¿hace frío?), una decisión (Sí/No) y dos acciones posibles. Recuerda: el organigrama no es el código, es el mapa del territorio. Dibujarlo antes de programar te ahorra tiempo y errores. Conecta directamente con el concepto de flujo de ejecución lineal que ya estudiaste. --- **Enunciado del taller** En este taller pondrás en práctica tu capacidad de traducir un problema cotidiano en un organigrama claro, correcto y legible. El objetivo no es producir un diagrama perfecto...
