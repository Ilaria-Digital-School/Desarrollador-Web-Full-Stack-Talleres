# Reescribe un algoritmo desordenado

RECORDATORIO TEÓRICO Un algoritmo es una secuencia finita, ordenada y sin ambigüedad de instrucciones que permiten resolver un problema o alcanzar un resultado preciso. La palabra clave aquí es «ordenada»: cada instrucción depende de las anteriores y prepara las siguientes. En algorítmica, el orden de ejecución no es opcional, es la esencia misma de la lógica. Un error muy frecuente en los principiantes consiste en confundir el «qué hacer» con el «en qué orden hacerlo». Por ejemplo, no se puede validar una contraseña antes de haberla leído, ni mostrar un resultado antes de haberlo calculado. El flujo de ejecución lineal impone una causalidad estricta: causa → proceso → efecto. Otro error habitual es redactar pasos demasiado vagos («gestionar el usuario») o demasiado granulares al punto de perder la visión global. La claridad y la granularidad adecuada son dos pilares de un buen pseudocódigo. Mini-ejemplo: el siguiente algoritmo está desordenado: 1. Mostrar «Acceso concedido» 2. Leer contraseña introducida por el usuario 3. Comparar con la contraseña almacenada 4. Pedir al usuario que introduzca su contraseña El orden correcto es: 4 → 2 → 3 → 1. Primero se pide, luego se lee, luego se compara, luego se muestra el resultado.
