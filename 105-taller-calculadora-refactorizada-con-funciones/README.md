# Taller: calculadora refactorizada con funciones

Recordatorio teórico: Una función es un bloque de código reutilizable que recibe datos de entrada (parámetros), ejecuta una tarea y normalmente devuelve un resultado con la palabra clave return. En ES6 podemos declararlas de forma clásica (function suma(a, b) { return a + b; }) o como funciones de flecha (const suma = (a, b) => a + b;). El modelo mental clave es la separación de responsabilidades: en lugar de escribir todo el código en un solo bloque, dividimos el programa en pequeñas piezas independientes, cada una con un único cometido. Esto se llama refactorizar: reorganizar el código para hacerlo más legible, mantenible y reutilizable, sin cambiar su comportamiento externo. Los errores frecuentes son: olvidar el return (la función devuelve undefined), confundir el nombre de la función con su llamada (definirla pero nunca invocarla), duplicar lógica en lugar de crear una función reutilizable, y modificar variables globales desde dentro de una función en vez de trabajar con parámetros y valores de retorno. También es común mezclar la lógica de cálculo con la lectura de datos del usuario, lo que dificulta las pruebas. Mini-ejemplo: en lugar de escribir let resultado = num1 + num2; console.log(resultado); repetido para cada operación, creamos funciones puras: const sumar = (a, b) => a + b; const restar = (a, b) => a - b;. Luego una función coordinadora decide cuál llamar según el operador. Así el cálculo queda aislado de la interfaz.
