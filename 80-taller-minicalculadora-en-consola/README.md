# Taller: minicalculadora en consola

Recordatorio teórico: Antes de empezar, recordemos los conceptos que ya hemos estudiado y que necesitarás aquí. Una variable es un contenedor con nombre que almacena un valor. En ES6 usamos 'let' para valores que pueden cambiar y 'const' para valores que no deben reasignarse. Los tipos primitivos más comunes son 'number' (números), 'string' (texto) y 'boolean' (verdadero/falso). Un punto crucial en una calculadora es la conversión de tipos: cuando lees datos desde la consola con 'prompt()', el valor recibido siempre es un 'string'. Si intentas sumar '5' + '3' obtendrás '53' (concatenación de texto) en lugar de 8. Para evitarlo, debes convertir los textos a números con 'Number()', 'parseInt()' o 'parseFloat()'. Los operadores aritméticos básicos son + (suma), - (resta), * (multiplicación), / (división) y % (módulo o resto). Además, los literales de plantilla (template literals), escritos con comillas invertidas `, permiten insertar variables dentro de una cadena usando ${variable}, lo que facilita mostrar resultados claros. Un error frecuente es olvidar la conversión de tipos, dividir entre cero (que produce 'Infinity') o no validar que el usuario haya introducido un número real. Mini-ejemplo: const a = Number(prompt('Primer número:')); const b = Number(prompt('Segundo número:')); console.log(`El resultado es: ${a + b}`); Con estas bases, ya tienes todo lo necesario para construir tu propia minicalculadora funcional en la consola del navegador. Enunciado del taller: Tu objetivo es programar una minicalculadora que funcione en la consola.
