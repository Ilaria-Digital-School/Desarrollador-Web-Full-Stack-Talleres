# Mini-checkpoint - Prepara un café

**Recordatorio teórico** Un algoritmo es una secuencia finita, ordenada y no ambigua de instrucciones que permite resolver un problema o alcanzar un resultado concreto. Tres conceptos son fundamentales para este taller: la secuenciación (las instrucciones se ejecutan una tras otra, en un orden preciso), la granularidad (cada paso debe ser suficientemente detallado para no dejar lugar a interpretaciones) y la claridad (cualquier persona que lea el pseudocódigo debe poder seguirlo sin conocimiento previo del problema). Un error frecuente en principiantes es saltarse pasos que parecen 'evidentes', como verificar si hay agua en la cafetera antes de encenderla. En algorítmica, nada se da por sobreentendido: el ordenador ejecuta exactamente lo que se le indica, ni más ni menos. Otro error habitual es mezclar el orden lógico de las operaciones, por ejemplo, intentar servir el café antes de que haya terminado de prepararse. Mini-ejemplo: para hacer una tostada, un algoritmo mal escrito diría 'coge el pan y tuéstalo'. Un algoritmo correcto diría: INICIO → Verificar que la tostadora está enchufada → Coger una rebanada de pan → Introducir el pan en la ranura → Ajustar el nivel de tostado → Pulsar la palanca → Esperar a que salte la tostadora → Retirar el pan → FIN. Este nivel de detalle es el que se espera en tu entrega. --- **Enunciado del taller** En este mini-checkpoint vas a movilizar todo lo aprendido en el capítulo de 'Algorítmica y lógica de programación': escritura de pseudocódigo, secuenciación de instrucciones, granularidad adecuada y claridad de expresión....
