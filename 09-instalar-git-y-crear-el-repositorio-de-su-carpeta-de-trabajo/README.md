# Instalar Git y crear el repositorio de su carpeta de trabajo

Recordatorio teórico: Fundamentos de Git Git es un sistema de control de versiones distribuido, esencial en el desarrollo profesional. Permite rastrear cambios en archivos y coordinar el trabajo entre varias personas. Un modelo mental útil es imaginar tres zonas principales: el directorio de trabajo (sus archivos locales), el área de staging o índice (donde prepara los cambios) y el repositorio (donde se almacenan los commits de forma permanente). Un error frecuente es inicializar un repositorio en la carpeta incorrecta, lo que luego dificulta la organización. Otro error es hacer commits con mensajes poco claros como "cambios", que no explican el propósito. También es común olvidar configurar el nombre y correo globales, lo que genera commits sin autor identificado. Un mini-ejemplo: si usted tiene 5 archivos en una carpeta y modifica 2, primero añade esos 2 al staging con 'git add'. Luego confirma esos cambios con un commit, por ejemplo, 'git commit -m "Añadir formulario de contacto básico"'. Esto crea un punto de restauración seguro en el historial. Git no solo guarda lo nuevo, sino una referencia al estado completo del proyecto en ese instante. Preparar el entorno de trabajo Este taller práctico tiene como objetivo consolidar su dominio de Git mediante su instalación y la creación de su primer repositorio local. Deberá aplicar los conceptos del control de versiones directamente en el entorno que ya maneja desde actividades anteriores. Usted trabajará de forma autónoma, siguiendo una serie de pasos concretos. Se espera que lea con atención y planifique su trabajo...
