# Tabla de multiplicar

Recordatorio teórico: Un bucle es una estructura que permite repetir un conjunto de instrucciones un número determinado de veces o mientras se cumpla una condición. En este taller trabajarás principalmente con el bucle 'for', ideal cuando conoces de antemano el número de repeticiones. Su modelo mental es sencillo: una variable de control (por ejemplo 'i') toma valores sucesivos (de 1 a 10, por ejemplo), y en cada vuelta el cuerpo del bucle se ejecuta con ese valor. Cuando anidas dos bucles (un bucle dentro de otro), el bucle interno completa todas sus vueltas por cada vuelta del bucle externo. Esta lógica es exactamente la que necesitas para generar una tabla de multiplicar completa: el bucle externo recorre las filas y el interno recorre las columnas. Un mini-ejemplo: para mostrar la tabla del 3, escribirías un bucle que recorra 'i' de 1 a 10 y muestre '3 x i = resultado'. Los errores frecuentes son: confundir los límites del bucle (empezar en 0 en lugar de 1, u olvidar el valor 10), invertir los operadores en la multiplicación, mezclar las variables de los bucles anidados, o concatenar mal el texto con los números al mostrar el resultado. Presta atención también a la indentación y a qué instrucciones pertenecen a cada bucle. Enunciado del workshop: Tu objetivo es escribir un programa que genere y muestre tablas de multiplicar utilizando bucles. Este ejercicio consolida todo lo visto sobre bucles 'for', bucles 'while', bucles anidados y el uso de variables. Debes trabajar de forma...
