# Instalar Visual Studio Code y abrir su carpeta de trabajo

Recordatorio teórico Un editor de código es un programa diseñado para escribir texto puro, sin formato oculto, que el ordenador puede leer tal cual. Visual Studio Code, abreviado VS Code, es un editor gratuito publicado por Microsoft y disponible para Windows, macOS y Linux. Su particularidad es que no trabaja solo con archivos aislados, sino con carpetas enteras. El modelo mental que debe retener es sencillo: abrir una carpeta en VS Code equivale a decirle «este es mi espacio de trabajo». La barra lateral Explorador muestra entonces el árbol de esa carpeta, con sus subcarpetas y archivos, exactamente como existen en el disco. Todo lo que usted cree desde el editor se guarda realmente en esa ubicación. Recuerde también la noción de ruta absoluta, vista en el capítulo sobre archivos y carpetas. Es la dirección completa de una carpeta o de un archivo desde la raíz del sistema. Por ejemplo, C:\Users\Ana\formacion-fullstack en Windows, o /Users/ana/formacion-fullstack en macOS. Hay tres errores frecuentes. El primero es abrir un archivo suelto en lugar de la carpeta. El segundo es abrir una carpeta demasiado amplia, como Documentos entera. El tercero es crear un archivo dentro de una subcarpeta sin darse cuenta. Mini-ejemplo: Ana elige Archivo > Abrir carpeta... y selecciona formacion-fullstack. En la parte superior del Explorador aparece FORMACION-FULLSTACK en mayúsculas. Esa es la raíz de su espacio de trabajo, y es ahí donde debe guardar los archivos que pertenecen a todo el proyecto.
