# Taller: declaración y visualización de variables

RECORDATORIO TEÓRICO En JavaScript moderno (ES6+), una variable es un contenedor con nombre que guarda un valor en memoria. Disponemos de tres palabras clave para declararlas. 'const' declara una constante cuyo enlace no puede reasignarse; se usa por defecto siempre que el valor no vaya a cambiar. 'let' declara una variable reasignable, útil para contadores o valores que evolucionan. 'var' es la forma antigua: tiene un ámbito de función (no de bloque) y provoca comportamientos poco intuitivos, por lo que la evitamos. El modelo mental es sencillo: cada declaración crea una etiqueta que apunta a un valor. Los tipos primitivos que manejará son: string (texto entre comillas), number (enteros y decimales), boolean (true/false), null (ausencia intencional de valor) y undefined (valor no asignado). Errores frecuentes: reasignar una 'const' (lanza un TypeError), usar una variable antes de declararla, confundir el operador de asignación '=' con la comparación '===', y olvidar las comillas en un string. Otro error típico es esperar que 'const' congele el contenido de un objeto: solo protege el enlace, no las propiedades internas. Mini-ejemplo: const nombre = 'Ana'; let edad = 30; edad = 31; console.log(nombre, edad); // Ana 31 console.log(typeof edad); // number El método console.log() imprime valores en la consola del navegador o de Node.js, y typeof revela el tipo de un dato. Estas dos herramientas serán su base para inspeccionar y depurar todo lo que declare durante el taller.
