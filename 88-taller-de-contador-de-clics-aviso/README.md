# Taller de : contador de clics (aviso)

RECORDATORIO TEÓRICO Hasta ahora has trabajado con variables, condiciones y funciones puras que reciben datos y devuelven resultados sin interactuar con una página web. En este taller darás el paso hacia la manipulación del DOM (Document Object Model), que es la representación en forma de árbol de los elementos HTML de una página. JavaScript puede leer y modificar ese árbol en tiempo real. El modelo mental clave es: el navegador construye el DOM a partir del HTML, y tu código selecciona nodos de ese árbol para observarlos o cambiarlos. Los conceptos esenciales son tres. Primero, la selección de elementos con métodos como 'document.querySelector("#miBoton")', que devuelve el primer elemento que coincide con el selector CSS indicado. Segundo, la escucha de eventos con 'elemento.addEventListener("click", funcion)', que ejecuta una función cada vez que ocurre una acción del usuario. Tercero, la actualización del contenido con propiedades como 'elemento.textContent' para cambiar el texto mostrado. Un mini-ejemplo: let contador = 0; const boton = document.querySelector('#boton'); boton.addEventListener('click', () => { contador++; document.querySelector('#salida').textContent = contador; }); Errores frecuentes: ejecutar el JavaScript antes de que el HTML exista (coloca el script al final del body o usa 'defer'); confundir '#' (id) con '.' (clase) en el selector; olvidar que 'addEventListener' recibe la función SIN paréntesis, porque no debes invocarla, sino pasarla como referencia para que el navegador la llame cuando corresponda. === ENUNCIADO DEL TALLER Tu objetivo es construir, desde cero, una pequeña aplicación web de una sola página que muestre un contador de clics.
