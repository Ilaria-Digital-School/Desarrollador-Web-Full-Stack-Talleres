# Taller de : conversiones de tipos sencillas

RECORDATORIO TEÓRICO En JavaScript, cada valor tiene un tipo primitivo (string, number, boolean, undefined, null, entre otros). Una conversión de tipo (o casting) consiste en transformar un valor de un tipo a otro. Existen dos formas: la conversión explícita, que tú provocas usando funciones como Number(), String(), Boolean() o parseInt(), y la conversión implícita (coerción), que JavaScript realiza automáticamente durante ciertas operaciones. El modelo mental clave es simple: cuando mezclas tipos, JavaScript intenta "adivinar" qué quieres hacer, y no siempre acierta. Por eso conviene controlar tú mismo las conversiones. Un error frecuente es sumar cadenas y números: '5' + 3 devuelve '53' (concatenación de texto), mientras que '5' - 3 devuelve 2 (resta numérica). Otro fallo típico es olvidar que Number('') vale 0, Number('abc') vale NaN, y que valores como '', 0, null, undefined y NaN son "falsy" (se convierten en false). Confundir == (compara con coerción) y === (compara sin coerción) también genera muchos bugs. Mini-ejemplo: let edadTexto = '25'; let edad = Number(edadTexto); // 25 (número) let mensaje = 'Tienes ' + edad + ' años'; // conversión implícita a texto console.log(typeof edad); // 'number' console.log(Boolean('')); // false Dominar estas conversiones es esencial: cuando recibas datos de un formulario o de una API, casi siempre llegarán como texto y tendrás que convertirlos correctamente.
