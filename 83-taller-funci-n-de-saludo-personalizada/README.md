# Taller: función de saludo personalizada

Recordatorio teórico: Una función es un bloque de código reutilizable que puede recibir datos de entrada (parámetros), ejecutar instrucciones y devolver un resultado con la palabra clave return. En ES6 disponemos de dos sintaxis principales. La declaración clásica: function saludar(nombre) { return 'Hola ' + nombre; }, y la función de flecha (arrow function): const saludar = (nombre) => `Hola ${nombre}`. Observa el uso de los template literals (plantillas de cadena) con acentos graves (backticks) y la interpolación ${...}, que permiten insertar variables directamente dentro del texto sin concatenar con +. El modelo mental es sencillo: piensa en una función como una máquina que recibe ingredientes (parámetros) y produce un plato (valor devuelto). Un error frecuente es olvidar el return, lo que hace que la función devuelva undefined. Otro error habitual es confundir mostrar en consola (console.log) con devolver un valor: console.log muestra algo en pantalla, pero no permite reutilizar el resultado. También es común mezclar comillas normales con backticks al usar plantillas. Mini-ejemplo: const bienvenida = (nombre, idioma) => idioma === 'es' ? `Hola ${nombre}` : `Hi ${nombre}`; console.log(bienvenida('Ana', 'es')); Este código define una función de flecha con dos parámetros y un operador ternario para elegir el idioma. Dominar las funciones es fundamental, porque son la base de toda la lógica que construirás más adelante en JavaScript y en el desarrollo web.
