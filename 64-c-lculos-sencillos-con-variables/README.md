# Cálculos sencillos con variables

RECORDATORIO TEÓRICO Una variable es un espacio con nombre en memoria que almacena un valor y que puede cambiar durante la ejecución del programa. El modelo mental correcto es imaginar una caja etiquetada: el nombre (etiqueta) permite identificarla, y el contenido (valor) puede sustituirse cuando lo necesites. Cada variable posee un tipo de dato: entero (int), real (float), cadena (string) o booleano (bool). Los cálculos sencillos se apoyan en operadores aritméticos: suma (+), resta (-), multiplicación (*), división (/), módulo o resto (%) y, en algunos lenguajes, potencia (**). El orden de evaluación respeta las prioridades matemáticas: primero paréntesis, luego multiplicaciones y divisiones, y por último sumas y restas. Un error frecuente es confundir la asignación (=) con la comparación de igualdad (== en muchos lenguajes). Otro fallo habitual es mezclar tipos: sumar un número con una cadena puede provocar concatenación en lugar de suma, o directamente un error. También es común olvidar que la división entre enteros puede truncar decimales según el lenguaje. Finalmente, muchos principiantes reutilizan el mismo valor sin actualizar la variable, obteniendo resultados desfasados. Mini-ejemplo en pseudocódigo: precio ← 20 cantidad ← 3 subtotal ← precio * cantidad iva ← subtotal * 0.21 total ← subtotal + iva MOSTRAR total Aquí cada variable guarda un resultado intermedio y el cálculo final combina esos valores. Este patrón (leer datos, calcular pasos intermedios, mostrar resultado) es la base de casi todos los programas que escribirás.
