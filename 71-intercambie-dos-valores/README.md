# Intercambie dos valores

RECORDATORIO TEÓRICO Una variable es un espacio con nombre en la memoria que almacena un valor. Cuando asignas un valor a una variable con una instrucción como 'a = 5', ese valor queda guardado bajo el nombre 'a'. El modelo mental correcto es imaginar cada variable como una caja etiquetada: puedes mirar dentro (leer su valor) o reemplazar su contenido (asignar un nuevo valor). Intercambiar dos valores significa que, si 'a' contiene 5 y 'b' contiene 9, después del intercambio 'a' contendrá 9 y 'b' contendrá 5. El error frecuente más importante es sobrescribir un valor antes de haberlo guardado. Si escribes 'a = b' y luego 'b = a', pierdes el valor original de 'a' para siempre: ambas variables terminan valiendo lo mismo. Por eso la técnica clásica utiliza una variable temporal que actúa como caja auxiliar. Guardas el valor de 'a' en 'temp', luego pones el valor de 'b' en 'a', y finalmente colocas el valor de 'temp' (el 'a' original) en 'b'. Mini-ejemplo: temp = a (temp vale 5) a = b (a vale 9) b = temp (b vale 5) Este patrón de los tres pasos es fundamental y reaparece constantemente en ordenamiento de datos, manipulación de listas y muchos algoritmos que verás más adelante. Comprender el porqué de la variable temporal es más importante que memorizar la sintaxis.
