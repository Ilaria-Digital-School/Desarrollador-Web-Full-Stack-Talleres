# Adaptar su página de inicio a las pantallas de móvil

Recordatorio teórico sobre diseño web responsivo El diseño web responsivo es un enfoque técnico y filosófico que busca que una página web se adapte fluidamente al dispositivo desde el cual es consultada. Esto se logra mediante una combinación de técnicas CSS, donde las media queries desempeñan un papel central. Una media query es una regla CSS que permite aplicar estilos condicionalmente, típicamente basándose en características del dispositivo como el ancho de la ventana gráfica (viewport width). Un modelo mental útil es considerar que se construye primero la experiencia para móvil (mobile-first) y luego se añaden reglas para adaptar el diseño a pantallas más grandes. Un error frecuente es el orden inverso (desktop-first), que a menudo conduce a una sobreescritura compleja de estilos. Otro error común es el uso de anchos fijos en píxeles, que impiden la adaptabilidad, y olvidar incluir la metaetiqueta viewport, vital para que los navegadores móviles escalen correctamente la página. Un mini-ejemplo ilustrativo sería una cuadrícula que en pantallas grandes muestre tres columnas lado a lado, pero que en móviles se apile en una sola columna. Esto se lograría con un contenedor usando `display: grid` y `grid-template-columns: repeat(3, 1fr);` para el diseño general. Luego, una media query como `@media (max-width: 768px) { grid-template-columns: 1fr; }` redefiniría la estructura cuando el ancho de la pantalla sea inferior a 768 píxeles.
