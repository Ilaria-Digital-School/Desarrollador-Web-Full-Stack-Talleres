# Taller de : ¿par o impar?

Recordatorio teórico: En programación, determinar si un número es par o impar es un problema clásico que se resuelve mediante el operador módulo (%). Este operador devuelve el resto de una división entera. Por ejemplo, 10 % 2 devuelve 0 porque 10 se divide exactamente entre 2, mientras que 7 % 2 devuelve 1 porque queda un resto. El modelo mental clave es simple: un número es par si el resto de su división entre 2 es igual a 0; en caso contrario, es impar. En JavaScript esto se traduce en la expresión `numero % 2 === 0`. Recuerda usar el operador de comparación estricta `===`, que compara valor y tipo, en lugar de `==`, para evitar conversiones implícitas inesperadas. Un error frecuente entre principiantes es olvidar convertir la entrada del usuario: cuando lees un valor desde un prompt o un input, JavaScript lo interpreta como cadena de texto (string), por lo que debes convertirlo con `Number()` o `parseInt()` antes de aplicar operaciones aritméticas. Otro error común es confundir el operador de asignación `=` con los de comparación `==` o `===`. Mini-ejemplo: ```js const numero = 8; if (numero % 2 === 0) { console.log(numero + ' es par'); } else { console.log(numero + ' es impar'); } ``` Este taller combina lo que ya aprendiste sobre variables, tipos, operadores aritméticos, condiciones if/else y conversión de tipos, aplicándolos a un caso concreto y verificable.
