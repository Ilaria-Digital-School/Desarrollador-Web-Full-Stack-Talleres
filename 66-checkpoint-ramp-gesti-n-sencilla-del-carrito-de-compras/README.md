# Checkpoint Ramp: gestión sencilla del carrito de compras

## Contexto En una tienda en línea, el carrito de compras es un elemento central: almacena los productos elegidos por el usuario, calcula totales y aplica reglas simples (cantidades, descuentos, impuestos). En este mini-proyecto pondrás en práctica lo aprendido sobre variables, tipos de datos, constantes, cálculos y secuencia de instrucciones para modelar la lógica de un carrito de compras SENCILLO, sin interfaz gráfica. El objetivo es razonar en términos de algoritmo, no de diseño web. ## Descripción del proyecto Deberás diseñar y programar un pequeño script (en pseudocódigo o en JavaScript/Python, a tu elección) que gestione un carrito de compras básico. El programa debe permitir representar productos con sus datos (nombre, precio unitario, cantidad), calcular el subtotal por producto, el total del carrito, aplicar un impuesto (IVA) y, opcionalmente, un descuento cuando se supera un umbral de compra. Este proyecto valida tu capacidad para: - Elegir los tipos de datos correctos (entero, real, cadena, booleano). - Declarar y asignar variables y constantes con nombres claros. - Encadenar instrucciones en una secuencia lógica coherente. - Realizar cálculos aritméticos correctos con variables. ## Alcance funcional mínimo (obligatorio) 1. Calcular el total del carrito sin impuestos. 4. Aplicar una tasa de IVA definida como CONSTANTE (por ejemplo, 21%) para obtener el total con impuestos. 5.
