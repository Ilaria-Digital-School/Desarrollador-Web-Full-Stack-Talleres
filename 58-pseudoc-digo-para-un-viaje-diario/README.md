# Pseudocódigo para un viaje diario

RECORDATORIO TEÓRICO Un algoritmo es una secuencia finita, ordenada y sin ambigüedad de instrucciones que permite resolver un problema o alcanzar un resultado. El pseudocódigo es la representación textual de un algoritmo en lenguaje natural estructurado: no es código real ejecutable, pero respeta una lógica precisa que podría traducirse directamente a cualquier lenguaje de programación. Su objetivo es separar la lógica del problema de la sintaxis técnica. Modelo mental clave: piensa en el pseudocódigo como un guion de teatro. Cada actor (variable) tiene un papel, cada escena (instrucción) ocurre en un orden definido, y el director (tú) decide qué pasa en cada momento. Las estructuras fundamentales son: la SECUENCIA (instrucciones ejecutadas una tras otra en orden), la CONDICIÓN (SI... ENTONCES... SINO) y el BUCLE (MIENTRAS o PARA). Errores frecuentes a evitar: olvidar inicializar variables antes de usarlas; confundir el orden de las instrucciones (por ejemplo, verificar si hay gasolina después de arrancar el coche); mezclar detalles técnicos irrelevantes con la lógica principal; escribir pseudocódigo ambiguo que podría interpretarse de varias maneras. Mini-ejemplo — Preparar un café: INICIO SI hay café en la máquina ENTONCES Encender la máquina Esperar a que el café esté listo Servir el café en una taza SINO Mostrar mensaje: 'No hay café disponible' FIN SI FIN Este ejemplo muestra cómo una acción cotidiana puede descomponerse en pasos lógicos, condicionales y secuenciales.
