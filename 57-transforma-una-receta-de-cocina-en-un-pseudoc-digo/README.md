# Transforma una receta de cocina en un pseudocódigo

RECORDATORIO TEÓRICO Un algoritmo es una secuencia finita, ordenada y no ambigua de instrucciones destinadas a resolver un problema o llevar a cabo una tarea. El pseudocódigo es una forma de representar ese algoritmo en lenguaje natural estructurado, a medio camino entre el idioma humano y un lenguaje de programación real. No existe una sintaxis universal para el pseudocódigo, pero sí convenciones ampliamente aceptadas: uso de palabras clave como INICIO, FIN, SI...ENTONCES...SINO, MIENTRAS, PARA, LEER, ESCRIBIR, y sangría para indicar bloques de instrucciones. Modelo mental clave: piensa en el pseudocódigo como una receta que una máquina sin sentido común pudiera ejecutar sin hacerte ninguna pregunta. Cada paso debe ser explícito, ordenado y completo. La máquina no infiere nada: si no lo dices, no lo hace. Errores frecuentes en principiantes: - Saltarse pasos obvios para un humano pero esenciales para una máquina (por ejemplo, olvidar declarar los ingredientes antes de usarlos). - Confundir el orden de las instrucciones, generando secuencias sin sentido lógico. - No contemplar casos alternativos (¿qué pasa si falta un ingrediente? ¿si el horno no está disponible?). - Usar lenguaje ambiguo como "cocinar un rato" en lugar de "esperar 30 minutos". Mini-ejemplo — Hacer una taza de té: INICIO LEER cantidad_agua Llenar la tetera con cantidad_agua Encender el fuego MIENTRAS agua NO esté hirviendo HACER Esperar 1 minuto FIN MIENTRAS Colocar la bolsa de té en la taza Verter el agua caliente en la taza Esperar 3 minutos Retirar la bolsa de té ESCRIBIR "Tu té está listo"...
