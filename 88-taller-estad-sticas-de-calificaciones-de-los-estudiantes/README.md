# Taller: estadísticas de calificaciones de los estudiantes

Recordatorio teórico: Antes de comenzar, repasemos los conceptos clave que vas a poner en práctica. Un array (arreglo) es una estructura de datos que almacena una colección ordenada de valores. En JavaScript ES6+ puedes recorrerlo y transformarlo con métodos de orden superior como forEach, map, filter y reduce, que reciben una función de retorno (callback). Por ejemplo, reduce permite acumular un resultado a partir de todos los elementos: [10, 15, 20].reduce((acc, val) => acc + val, 0) devuelve 45. Este método es ideal para calcular sumas, promedios o máximos. El modelo mental correcto es pensar en los datos como un flujo que puedes filtrar, transformar y agregar sin modificar el array original. Aprovecha las funciones flecha (arrow functions) para escribir callbacks concisos, la desestructuración para extraer propiedades de objetos, y las plantillas literales (template literals) con backticks para construir cadenas dinámicas. Los errores frecuentes incluyen: olvidar el valor inicial en reduce (lo que provoca resultados inesperados con arrays vacíos), confundir map (devuelve un nuevo array) con forEach (no devuelve nada), y dividir entre cero al calcular promedios sobre listas vacías.
