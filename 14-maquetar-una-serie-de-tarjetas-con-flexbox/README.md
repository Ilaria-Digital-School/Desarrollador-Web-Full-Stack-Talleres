# Maquetar una serie de tarjetas con Flexbox

Recordatorio teórico sobre Flexbox Flexbox es un modelo de diseño en CSS diseñado para distribuir el espacio entre los elementos de un contenedor, incluso cuando su tamaño es dinámico o desconocido. Su objetivo principal es ofrecer un método de maquetación más eficiente, con alineación y distribución de espacio más predecibles. El modelo mental clave gira en torno al concepto de contenedor flex y elementos flex. Un contenedor flex se define con `display: flex;`. Dentro de él, los elementos hijos se convierten en elementos flex. El diseño se controla mediante dos ejes: el eje principal, definido por `flex-direction` (que puede ser fila o columna), y el eje secundario, perpendicular al principal. Las propiedades como `justify-content` controlan la alineación a lo largo del eje principal, mientras que `align-items` lo hace en el eje secundario. Un error frecuente es confundir `flex-grow`, `flex-shrink` y `flex-basis`. La propiedad abreviada `flex` acepta tres valores en ese orden. `flex-grow` define cómo un elemento crece para ocupar espacio extra (0 significa que no crece). `flex-shrink` define cómo se reduce si falta espacio (0 significa que no se reduce). `flex-basis` establece el tamaño inicial ideal (por ejemplo, `200px` o `30%`). Un mini-ejemplo práctico: un contenedor con `display: flex;` y `flex-wrap: wrap;` contiene tres hijos. Si a cada hijo se le asigna `flex: 1 0 200px;`, cada uno tendrá una base de 200 píxeles, crecerán proporcionalmente (`flex-grow: 1`) si hay espacio extra, pero nunca se reducirán (`flex-shrink: 0`).
