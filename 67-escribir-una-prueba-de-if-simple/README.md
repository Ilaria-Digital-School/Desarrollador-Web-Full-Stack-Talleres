# Escribir una prueba de IF simple

RECORDATORIO TEÓRICO Una condición (o prueba) permite a un programa tomar decisiones y ejecutar instrucciones solo cuando se cumple un criterio determinado. La estructura fundamental es el IF: 'si una condición es verdadera (true), entonces ejecuta este bloque de código'. La condición es siempre una expresión que devuelve un valor booleano: verdadero o falso. Para construirla se utilizan operadores de comparación como == (igual a), != (distinto de), > (mayor que), < (menor que), >= y = 18 ENTONCES mostrar "Eres mayor de edad" FIN SI Aquí, como 20 es mayor o igual que 18, la condición es verdadera y se muestra el mensaje. Errores frecuentes: olvidar cerrar el bloque, usar = en lugar de ==, o poner una condición que nunca puede ser verdadera. Un IF simple no necesita ELSE: solo actúa cuando la condición se cumple. ENUNCIADO DEL WORKSHOP En este taller vas a poner en práctica la escritura de pruebas IF simples resolviendo varios pequeños problemas de decisión. El objetivo es que domines la lógica de una condición antes de abordar estructuras más complejas como IF/ELSE o condiciones múltiples. Puedes usar pseudocódigo o el lenguaje que prefieras (por ejemplo JavaScript o Python), pero lo esencial es la lógica correcta. Deberás resolver los siguientes casos, cada uno con su propia variable de partida y su prueba IF: (1) Verifica si un número guardado en una variable 'temperatura' es superior a 30 y, si es así, muestra el mensaje "Hace calor".
