# Taller: gestión de una lista de tareas en una consola

RECORDATORIO TEÓRICO Antes de comenzar, repasemos los conceptos clave que has visto en los capítulos anteriores. Una variable declarada con 'let' o 'const' te permite almacenar datos: usa 'const' cuando el valor no cambiará de referencia (como un array cuyo contenido modificas con métodos) y 'let' cuando reasignarás el valor. Un array es una colección ordenada de elementos; los métodos esenciales para manipularlo son 'push()' para añadir al final, 'splice()' para eliminar por índice, y el bucle 'for' o 'forEach()' para recorrerlo. Una función encapsula un bloque de código reutilizable: recibe parámetros, ejecuta instrucciones y puede devolver un resultado con 'return'. Las funciones flecha ES6 ('const f = () => {}') ofrecen una sintaxis compacta. El modelo mental correcto es pensar en tu lista de tareas como un array de objetos, donde cada tarea es un objeto con propiedades como 'id', 'texto' y 'completada'. Cada acción del usuario (añadir, eliminar, marcar) es una función que modifica ese array y luego lo muestra por consola con 'console.log()'. Errores frecuentes: olvidar que 'splice()' modifica el array original y usa índices (no ids); confundir la asignación '=' con la comparación '===' dentro de condiciones; y no gestionar el caso de una lista vacía. Un mini-ejemplo: `const tareas = []; const agregar = (texto) => tareas.push({ id: Date.now(), texto, completada: false }); agregar('Estudiar JS'); console.log(tareas);`.
