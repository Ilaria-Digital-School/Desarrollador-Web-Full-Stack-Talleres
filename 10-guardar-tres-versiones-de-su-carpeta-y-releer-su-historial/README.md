# Guardar tres versiones de su carpeta y releer su historial

Recordatorio teórico sobre versionado con Git Un sistema de control de versiones es una herramienta fundamental para el desarrollo de software profesional. Permite guardar instantáneas de su proyecto a través del tiempo, marcar puntos estables y revertir cambios. Git, el sistema más extendido, opera a nivel de directorio (repositorio) y se usa mediante comandos en el terminal. Las operaciones clave son `git add` para seleccionar los cambios que quiere guardar en la próxima instantánea, `git commit` para crear efectivamente esa instantánea con un mensaje descriptivo, y `git log` para consultar la línea de tiempo de cambios. Cometer errores es parte del aprendizaje: un error frecuente es no agregar (`add`) los archivos modificados antes de confirmar (`commit`), lo que resulta en un repositorio vacío. Otro error común es escribir mensajes de commit vagos como "cambio", que no ayudan a comprender el historial más adelante. Imagine un archivo `proyecto.txt` que inicialmente contiene "Versión 1". Tras modificarlo a "Versión 1 - Modificación A", ejecutaría `git add proyecto.txt` seguido de `git commit -m "Añadir modificación A al archivo principal"`. Este proceso crea un commit. Al realizar dos modificaciones más y confirmarlas con mensajes claros, tendrá un historial de tres cambios fácilmente consultable.
