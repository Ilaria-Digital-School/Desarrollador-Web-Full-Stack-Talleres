# Crear, renombrar y organizar archivos desde el editor

Recordatorio teórico Un editor de código como Visual Studio Code es la herramienta central para crear y gestionar los archivos de un proyecto de desarrollo. Un archivo es un conjunto de datos persistentes, identificado por un nombre y una extensión (como .html, .css, .js) que informa a su ordenador y al editor sobre su tipo y cómo tratarlo. El modelo mental clave es la estructura de árbol de las carpetas (directorios) y archivos, donde cada elemento tiene una ubicación única llamada ruta. Organizar lógicamente estos elementos desde el inicio del proyecto evita la confusión y acelera el trabajo. Un error frecuente es crear archivos sueltos en el directorio incorrecto o nombrarlos con espacios, caracteres especiales o sin la extensión apropiada, lo que genera problemas para localizarlos y ejecutarlos. Por ejemplo, para un sitio web básico, usted tendría una carpeta raíz llamada «mi_sitio». Dentro de ella, crearía una carpeta «css» para contener un archivo «estilos.css» y una carpeta «js» para un archivo «codigo.js». El archivo principal «index.html» residiría directamente en «mi_sitio». Esta separación por función es la base de una organización profesional. Objetivo y enunciado del taller En este taller, usted pondrá en práctica los conceptos de creación, nombramiento y organización de archivos y carpetas directamente desde Visual Studio Code. El objetivo final es construir la estructura de carpetas y archivos de origen para un sitio web simple y ficticio, siguiendo una especificación precisa.
