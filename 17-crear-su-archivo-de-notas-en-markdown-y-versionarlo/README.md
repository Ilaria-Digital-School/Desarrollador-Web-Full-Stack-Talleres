# Crear su archivo de notas en Markdown y versionarlo

Recordatorio teórico Tomar notas sistemáticas es una práctica fundamental para desarrolladores profesionales. Este taller integra dos competencias técnicas clave: la escritura de documentación mediante Markdown y el control de versiones con Git. Markdown es un lenguaje de marcado ligero que permite formatear texto plano de manera legible y convertirlo a HTML u otros formatos. Su sintaxis utiliza caracteres especiales como almohadillas para títulos, asteriscos para énfasis y guiones para listas. Los errores frecuentes incluyen olvidar espacios después de los símbolos o anidar incorrectamente los elementos. Git es un sistema de control de versiones distribuido que registra los cambios en archivos a lo largo del tiempo. Su modelo mental se basa en commits (instantáneas), ramas y repositorios. Un error común es realizar commits demasiado grandes, que mezclan cambios no relacionados, dificultando el seguimiento. Un ejemplo concreto: para crear un título de nivel dos en Markdown, se escribe '## Mi título'. Para versionar este archivo, primero se inicializa un repositorio con 'git init', luego se añade el archivo con 'git add notas.md' y finalmente se crea un commit con 'git commit -m "Añade título principal"'. Este directorio albergará tanto su archivo de notas como el repositorio Git local.
