# Declarar y asignar variables

**Recordatorio teórico** Una variable es un contenedor con nombre que almacena un valor en la memoria durante la ejecución de un programa. Declarar una variable consiste en reservar ese espacio de memoria y darle un identificador. Asignar una variable consiste en colocar un valor concreto en ese espacio. Estos dos actos pueden realizarse en el mismo momento o en momentos distintos. El modelo mental más útil es el de una caja etiquetada: la etiqueta es el nombre de la variable, el contenido es su valor, y el tipo (entero, texto, decimal, booleano) describe qué clase de datos puede contener esa caja. Cambiar el contenido de la caja es una reasignación; la etiqueta no cambia, pero lo que hay dentro sí. Errores frecuentes en esta etapa: confundir la declaración con la asignación (se puede declarar sin asignar, y el valor será indefinido o nulo según el lenguaje); utilizar un nombre de variable que no describe su contenido ('x', 'temp1', 'cosa'); olvidar que en pseudocódigo las mayúsculas/minúsculas deben mantenerse consistentes; y mezclar tipos de datos sin querer (por ejemplo, guardar el texto "25" donde se espera el número 25). Mini-ejemplo en pseudocódigo: DECLARAR edad COMO ENTERO DECLARAR nombre COMO TEXTO asignar edad ← 32 asignar nombre ← "Lucía" MOSTRAR "Hola, " + nombre + ". Tienes " + edad + " años."
