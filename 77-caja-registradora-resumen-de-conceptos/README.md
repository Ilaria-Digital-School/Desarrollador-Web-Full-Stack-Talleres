# Caja registradora: resumen de conceptos

## Presentación del proyecto Este mini-proyecto integra todos los conceptos algorítmicos vistos hasta ahora: variables, condiciones, bucles, funciones (parámetros, alcance de variables, retorno de valores) y listas/tablas. Deberás desarrollar un programa de **caja registradora** funcional que simule el proceso de compra de un cliente en una tienda. El programa debe permitir gestionar un carrito de productos, calcular totales, aplicar descuentos, gestionar el pago y generar un ticket de compra. Es un proyecto directamente conectado con situaciones reales del mundo profesional del desarrollo. ## Descripción funcional El programa debe cubrir las siguientes funcionalidades: 1. **Catálogo de productos**: una lista de productos, cada uno con nombre y precio unitario (puedes usar listas o estructuras equivalentes). 2. **Añadir productos al carrito**: el usuario selecciona productos y cantidades. 3. **Cálculo del subtotal**: recorrer el carrito y sumar el importe de cada línea (precio × cantidad). 4. **Aplicación de descuentos**: por ejemplo, un descuento porcentual si el subtotal supera un umbral determinado. 5. **Cálculo del total final** (con o sin impuestos, según elijas). 6. **Gestión del pago**: el cliente introduce una cantidad, el programa calcula el cambio a devolver y verifica que el pago sea suficiente. 7. **Generación del ticket**: mostrar el detalle de la compra (líneas, subtotal, descuentos, total, pago, cambio). ## Competencias validadas Este proyecto valida tu capacidad para descomponer un problema en funciones reutilizables, manipular listas, controlar el flujo con bucles y condiciones, gestionar el alcance de las variables y documentar tu código correctamente.
