# Descomponer una tarea cotidiana en instrucciones precisas

Recordatorio teórico La programación de software exige estructurar problemas en pasos lógicos que una máquina pueda ejecutar. Este taller práctico fundamenta ese proceso de pensamiento esencial. La descomposición algorítmica es dividir una tarea compleja en instrucciones elementales y secuenciales, evitando ambigüedades. La precisión es crítica: cada instrucción debe ser atómica, verificable y comenzar con un verbo de acción. El modelo mental consiste en imaginar que se explica el proceso a alguien sin conocimiento previo o a un robot literal. Este enfoque obliga a especificar cada detalle operativo, omitiendo suposiciones implícitas. Un error frecuente es el uso de lenguaje vago como "preparar" o "ajustar" sin definir cómo. Otro error es omitir condiciones de inicio o final, dejando el proceso incompleto. La falta de especificidad cuantitativa es otro fallo común. Mini-ejemplo: "Hervir agua" se descompone como: 1. Llenar la tetera con 500 ml de agua. 2. Colocar la tetera sobre el quemador central. 3. Girar el mando de temperatura a la posición máxima. 4. Esperar hasta que un silbido continuo de 3 segundos suene. 5. Girar el mando a la posición cero. La descomposición funcional es un ejercicio de disciplina intelectual clave para el desarrollo de software, ya que transforma la ambigüedad natural del lenguaje humano en la exactitud requerida por un compilador. Elegir y delimitar una tarea Usted debe comenzar por seleccionar una actividad cotidiana de complejidad media. Elija una tarea que requiera entre diez y veinte pasos discretos para ser completada correctamente. Evite tareas abstractas como "organizar una reunión". Prefiera...
