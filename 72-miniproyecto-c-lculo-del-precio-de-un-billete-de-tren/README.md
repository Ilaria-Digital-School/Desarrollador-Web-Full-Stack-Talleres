# Miniproyecto: cálculo del precio de un billete de tren

Recordatorio teórico Antes de empezar, repasemos los conceptos clave que has visto en las actividades anteriores. Una variable es un contenedor con nombre que almacena un valor (un número, un texto, un booleano). Las condiciones (if, else if, else) permiten que tu programa tome decisiones distintas según el estado de esas variables. Los operadores de comparación (===, !==, , =) devuelven un booleano (true o false), y los operadores lógicos (&& para 'Y', || para 'O', ! para 'NO') permiten combinar varias condiciones en una sola prueba. El modelo mental que debes tener es el de un árbol de decisiones: en función de los datos de entrada, tu código recorre una rama u otra y produce un resultado. Por ejemplo: si la edad es menor que 12, aplica una tarifa infantil; si no, aplica la tarifa normal. Mini-ejemplo: let edad = 8; let precioBase = 30; let precioFinal; if (edad < 12) { precioFinal = precioBase * 0.5; } else { precioFinal = precioBase; } Errores frecuentes: confundir el operador de asignación (=) con el de comparación (===); olvidar que un descuento se aplica sobre el precio base y no sobre un precio ya modificado; encadenar condiciones que se solapan y provocan que nunca se alcance una rama; y no cubrir todos los casos posibles (dejar valores sin resultado).
