# Reorganizar una carpeta usando solo el terminal

Recordatorio teórico En el desarrollo de software, la organización de los archivos es fundamental para la eficiencia y la colaboración. Un proyecto bien estructurado facilita la navegación, el mantenimiento y la escalabilidad. Los comandos del terminal ofrecen un control potente y preciso sobre el sistema de archivos, permitiendo operaciones masivas de forma rápida y scriptable, lo cual es una habilidad esencial para cualquier desarrollador. Definimos los comandos clave para este taller: `ls` lista el contenido de un directorio; `cd` cambia el directorio de trabajo; `mkdir` crea nuevos directorios o carpetas; `mv` mueve o renombra archivos y directorios; `cp` copia archivos; `rm` elimina archivos; y `pwd` muestra la ruta del directorio actual. El modelo mental crucial es entender el sistema de archivos como un árbol jerárquico donde usted navega y manipula nodos (archivos y carpetas) desde un punto llamado directorio de trabajo. Un error frecuente es ejecutar comandos sin verificar primero en qué directorio se encuentra, lo que puede llevar a mover o eliminar archivos en la ubicación incorrecta. Otro error común es no utilizar rutas relativas (como `./archivo.txt`) o absolutas (como `/home/usuario/proyecto/archivo.txt`) de forma consistente, causando confusión. También es peligroso usar `rm` sin una comprobación previa, ya que la eliminación es permanente. Mini-ejemplo: imagine un directorio `ejemplo/` con tres archivos: `script.js`, `styles.css` y `notas.txt`. Primero, usaría `ls` para verlos. Luego, `mkdir codigo_doc` para crear una nueva carpeta. Finalmente, `mv script.js styles.css codigo_doc/` movería los dos primeros archivos, dejando `notas.txt` en la raíz. Este es el patrón básico que se aplicará...
