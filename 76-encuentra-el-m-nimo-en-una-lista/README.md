# Encuentra el mínimo en una lista

RECORDATORIO TEÓRICO Una lista (o array) es una estructura de datos que almacena varios valores en un orden determinado, accesibles mediante un índice que suele comenzar en 0. Buscar el mínimo de una lista significa recorrer todos sus elementos y determinar cuál tiene el valor más pequeño. El modelo mental es sencillo: imagina que revisas una fila de objetos de peso variable con los ojos vendados; tomas el primero como referencia (el 'candidato a mínimo') y comparas cada objeto siguiente con tu referencia actual; si encuentras uno más ligero, actualizas tu referencia. Al final del recorrido, tu referencia es el mínimo real. En pseudocódigo: se inicializa una variable `minimo` con el primer elemento de la lista, luego se recorre la lista desde el segundo elemento; para cada elemento, si es menor que `minimo`, se reemplaza `minimo` por ese valor. Errores frecuentes: inicializar `minimo` en 0 (falla si todos los valores son positivos... o negativos), no gestionar el caso de una lista vacía, o confundir el índice con el valor almacenado. Otro error clásico es comenzar el recorrido en el índice 0 pero olvidar inicializar correctamente la referencia. Mini-ejemplo: para la lista [7, 3, 9, 1, 5], se inicia con minimo = 7, luego 3 < 7 → minimo = 3, luego 9 no cambia nada, luego 1 < 3 → minimo = 1, luego 5 no cambia nada. Resultado: el mínimo es 1.
