# Ver y recorrer el código fuente de tres sitios web que utiliza

Recordatorio teórico y modelo mental Todo sitio web que usted visita está construido con código fuente que su navegador interpreta para renderizar la página. Este código es accesible publicamente y su examen es una práctica fundamental del desarrollo. El código fuente incluye principalmente documentos HTML para la estructura, CSS para los estilos y JavaScript para la interacción. Los navegadores modernos integran herramientas de desarrollo que permiten a los programadores inspeccionar y depurar este código en tiempo real. Un modelo mental útil es imaginar que cada página web es un proyecto de carpintería. El HTML son los planos y la estructura de la madera, el CSS es la pintura y los acabados, mientras que JavaScript son los mecanismos (como bisagras o cajones) que permiten el movimiento y la funcionalidad. Un error frecuente entre principiantes es limitarse a ver el código HTML inicial sin explorar los recursos dinámicamente cargados o las hojas de estilo. Otro error es no comprender que el código que se ve puede estar transformado por herramientas de construcción y no ser el código original escrito por los desarrolladores. Mini-ejemplo: Abra cualquier página, haga clic derecho y seleccione 'Ver código fuente de la página'. Verá el documento HTML crudo. Si cambia a las herramientas de desarrollo (F12) y selecciona el ícono de inspección (flecha en un cuadrado), podrá pasar el cursor sobre elementos visuales para ver su código correspondiente inmediatamente.
