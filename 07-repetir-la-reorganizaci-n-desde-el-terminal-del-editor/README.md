# Repetir la reorganización desde el terminal del editor

Recordatorio teórico: Fundamentos del terminal y flujo de trabajo integrado El terminal es una interfaz de línea de comandos que permite interactuar directamente con el sistema operativo mediante comandos de texto. Un flujo de trabajo eficiente en desarrollo integra esta herramienta con el editor de código, permitiendo realizar todas las acciones desde un único entorno. Este modelo mental combina la creación y edición de archivos con el control del sistema de archivos sin cambiar de aplicación. Los errores frecuentes incluyen no verificar el directorio actual antes de ejecutar comandos, lo que lleva a operaciones en ubicaciones incorrectas, y utilizar nombres de archivos o rutas con errores tipográficos. Otro error común es no listar el contenido después de operaciones críticas como mover o eliminar, perdiendo así la confirmación visual de los cambios realizados. Un mini-ejemplo ilustrativo sería: usted está en el directorio 'proyecto' y necesita mover todos los archivos de tipo texto a una subcarpeta 'docs'. Primero, verificará su ubicación con 'pwd'. Luego, listará los archivos con 'ls' para identificar los '.txt'. Finalmente, ejecutará 'mv *.txt docs/' y confirmará con 'ls docs/' para ver los archivos movidos. Enunciado del workshop: Replicación de una estructura organizada Para este taller, usted deberá demostrar su dominio del uso del terminal integrado en su editor de código. Partiendo de una estructura desorganizada, necesitará aplicar los comandos aprendidos para alcanzar un estado objetivo definido con precisión.
