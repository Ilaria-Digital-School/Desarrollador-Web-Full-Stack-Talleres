# Desarrollador Full-Stack

Convertirse en desarrollador full-stack, desde cero hasta nivel de grado: diseñar, desarrollar, proteger, probar y desplegar aplicaciones web y móviles. Competencias: comprender el funcionamiento de los ordenadores, los sistemas y las redes; programar en JavaScript y en Python, con programación orientada a objetos; analizar una necesidad y diseñar un sistema (modelado de datos, maquetas, UML); diseñar y consultar bases de datos SQL y NoSQL; desarrollar interfaces web accesibles con HTML, CSS y Angular; desarrollar API REST con Node y Express; proteger una aplicación web; probar, contenerizar y desplegar con integración continua; diseñar una arquitectura de software multicapa; administrar redes y bases de datos; analizar datos con Python; dirigir un proyecto informático con metodología ágil; respetar el derecho y la ética digitales. Los talleres se basan en ejercicios y en los proyectos que usted construye a lo largo del programa, entre ellos su tienda en línea; se proporcionan los datos necesarios.

[Ver el taller completo](https://www.ilaria-academy.com/nextjob/full-stack-web-developer/es/)
