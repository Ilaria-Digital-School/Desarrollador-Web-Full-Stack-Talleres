# Para: calcula un factorial

Recordatorio teórico: El bucle 'para' (for) es una estructura de repetición que ejecuta un bloque de instrucciones un número conocido de veces. A diferencia del bucle 'mientras' (while), que repite mientras una condición sea verdadera, el bucle 'para' se apoya en un contador que avanza de un valor inicial a un valor final con un paso definido. Modelo mental: imagina una lista de números (por ejemplo del 1 al 5) por la que el bucle recorre uno a uno, ejecutando la misma acción en cada paso. El factorial de un número entero N, escrito N!, es el producto de todos los enteros positivos desde 1 hasta N. Por ejemplo, 5! = 1 × 2 × 3 × 4 × 5 = 120. Por convención, 0! = 1. Un mini-ejemplo en pseudocódigo: 'resultado = 1; para i de 1 hasta N: resultado = resultado × i; mostrar resultado'. Aquí la variable 'resultado' acumula el producto en cada iteración. Errores frecuentes: inicializar 'resultado' en 0 (todo se anula al multiplicar), olvidar el caso especial 0! = 1, confundir los límites del bucle (empezar en 0 en lugar de 1, o detenerse antes de N), y no gestionar los números negativos, para los que el factorial no está definido. Comprender esta acumulación progresiva es la clave del taller. Enunciado del taller: Tu objetivo es escribir un programa que calcule el factorial de un número entero introducido por el usuario, utilizando obligatoriamente un bucle 'para' (for). El programa debe ser funcional, robusto y devolver...
