# Taller de : catálogo de productos (conjunto de objetos)

Recordatorio teórico: En JavaScript, un objeto literal es una estructura que agrupa datos relacionados bajo la forma de pares clave-valor, por ejemplo { nombre: 'Camiseta', precio: 19.99, stock: 40 }. Cuando necesitamos manipular varios objetos del mismo tipo, los almacenamos dentro de un array (un conjunto de objetos): const catalogo = [obj1, obj2, obj3]. El modelo mental que debes tener es sencillo: un array es una lista ordenada, y cada elemento de esa lista es un objeto con sus propias propiedades. Para recorrer este conjunto usarás bucles (for, for...of) o, mejor aún, los métodos de array de ES6 que ya estudiaste: map() para transformar cada elemento y devolver un nuevo array, filter() para conservar solo los elementos que cumplen una condición, y reduce() para acumular un resultado único (una suma, un promedio, un conteo). Los errores frecuentes son: olvidar que map() y filter() devuelven un array NUEVO y no modifican el original; confundir filter (que devuelve elementos) con find (que devuelve un solo elemento); acceder a una propiedad inexistente y obtener undefined; y olvidar el return dentro de la función de callback cuando se usan llaves. Un mini-ejemplo: const caros = catalogo.filter(p => p.precio > 50); const total = catalogo.reduce((suma, p) => suma + p.precio, 0). Dominar estas operaciones es la base para tratar datos reales en aplicaciones web. Enunciado del taller: Tu misión consiste en construir y explotar un catálogo de productos representado por un array de objetos. Cada producto debe contener al menos las propiedades: id, nombre, categoria,...
