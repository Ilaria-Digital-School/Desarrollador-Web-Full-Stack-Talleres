# Crear la estructura de su carpeta de trabajo para la formación

Recordatorio teórico fundamental Un sistema de archivos organiza la información en un ordenador mediante archivos y carpetas. Un archivo es una unidad de datos con un nombre y una extensión que indica su tipo, como `.html` o `.js`. Una carpeta, o directorio, es un contenedor que agrupa archivos y otras carpetas, creando una jerarquía. La ruta describe la ubicación de un archivo en esta jerarquía. Puede ser absoluta, partiendo desde la raíz del sistema, o relativa, partiendo desde la ubicación actual. La estructura en árbol visualiza esta relación padre-hijo entre carpetas. Un error frecuente es crear una lista plana de archivos sin agruparlos, lo que pronto se vuelve inmanejable. Otro es diseñar una jerarquía excesivamente profunda, dificultando el acceso a los archivos. El modelo mental clave es pensar en categorías y subcategorías, agrupando elementos similares. Por ejemplo, para un pequeño proyecto 'MiWeb', una estructura lógica sería: una carpeta raíz `MiWeb/`. Dentro, carpetas como `html/` para páginas, `css/` para estilos y `img/` para imágenes. Así, la ruta relativa a una imagen desde una página HTML sería `../img/logo.jpg`. Definir el objetivo y el alcance Este taller tiene como objetivo que usted diseñe y cree la estructura base de carpetas donde almacenará todo el trabajo de su formación como desarrollador full-stack. Esta organización es fundamental para su eficiencia diaria y su capacidad de gestionar proyectos complejos.
