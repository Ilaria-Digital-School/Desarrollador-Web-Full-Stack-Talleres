# Construir una barra de navegación con Flexbox

Recordatorio teórico Flexbox es un modelo de diseño unidimensional que permite distribuir elementos a lo largo de un eje principal o cruzado. Los elementos se colocan dentro de un contenedor flexible o flex container, que se define con la propiedad `display: flex`. Una vez activado, sus elementos hijos se convierten en ítems flexibles. El eje principal se define con `flex-direction`, que puede ser `row` (horizontal) o `column` (vertical). En el eje principal, `justify-content` controla la alineación y el espacio entre los ítems (como `space-between` o `center`). En el eje cruzado, `align-items` controla la alineación vertical. Un error común es aplicar propiedades de Flexbox directamente a los hijos sin haber configurado correctamente el contenedor padre. Otro error es olvidar que `flex-direction: column` cambia la orientación de los ejes, haciendo que `justify-content` controle la alineación vertical y `align-items` la horizontal. Un mini ejemplo: un contenedor con `display: flex; flex-direction: row; justify-content: space-between;` coloca sus tres hijos de 100px de ancho distribuidos equitativamente a lo largo del ancho disponible. Definir el proyecto Usted va a construir una barra de navegación horizontal para un sitio web utilizando Flexbox. Esta barra debe ser semántica, accesible y completamente responsiva. El diseño debe adaptarse a pantallas de escritorio y móviles. Su tarea es crear los archivos HTML y CSS necesarios que repliquen la funcionalidad y el diseño de una barra de navegación moderna.
