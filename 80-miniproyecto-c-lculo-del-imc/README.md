# Miniproyecto : cálculo del IMC

Recordatorio teórico: Una variable es un espacio de memoria con un nombre que almacena un valor que puede cambiar durante la ejecución de un programa. El estado de un programa es el conjunto de valores que tienen sus variables en un momento dado. Recuerda los tipos de datos fundamentales: los enteros (integer) para números sin decimales, los reales (float o double) para números con decimales, las cadenas (string) para texto y los booleanos (boolean) para valores verdadero/falso. Un cálculo aritmético combina variables y operadores (+, -, *, /) siguiendo un orden de precedencia. El modelo mental correcto es: primero declaro y asigno mis variables de entrada, luego aplico una fórmula sobre ellas, y finalmente guardo el resultado en una nueva variable de salida. Errores frecuentes: confundir el tipo de dato (tratar una cadena '75' como si fuera un número), olvidar convertir la entrada del usuario a número antes de operar, y equivocarse en la precedencia de operadores olvidando los paréntesis. Otro error habitual es dividir por cero o usar unidades incoherentes. Mini-ejemplo: para calcular una superficie, declaro base = 5 y altura = 3, ambos enteros; luego aplico superficie = base * altura, obteniendo 15. Si trabajo con decimales, uso el tipo real: precio = 19.99. En este workshop aplicarás exactamente esta lógica: entradas, fórmula, salida.
