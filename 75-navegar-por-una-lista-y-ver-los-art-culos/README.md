# Navegar por una lista y ver los artículos

Recordatorio teórico Una lista (también llamada array o tabla) es una estructura de datos que almacena varios valores de forma ordenada, cada uno accesible mediante un índice. En la mayoría de los lenguajes de programación, el primer elemento se encuentra en el índice 0, el segundo en el índice 1, y así sucesivamente. El modelo mental que debes retener es el de una fila de casilleros numerados: cada casillero contiene un valor y tiene un número único que permite localizarlo. Navegar (o recorrer) por una lista consiste en pasar por cada uno de sus elementos, generalmente con un bucle, para leerlos, mostrarlos o tratarlos. Existen varias formas de recorrer una lista: un bucle 'for' clásico con un contador que va del índice 0 hasta la longitud de la lista menos uno, o un bucle 'for...of' que recorre directamente los valores. Un mini-ejemplo en JavaScript: 'const frutas = ["manzana", "pera", "uva"]; for (let i = 0; i < frutas.length; i++) { console.log(frutas[i]); }' muestra los tres valores uno por uno.
