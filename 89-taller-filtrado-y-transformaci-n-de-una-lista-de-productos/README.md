# Taller: filtrado y transformación de una lista de productos

RECORDATORIO TEÓRICO En JavaScript moderno (ES6+), los arrays disponen de métodos de orden superior que permiten manipular colecciones de datos sin recurrir a bucles manuales. Los tres pilares son: `filter()`, que devuelve un nuevo array con los elementos que cumplen una condición (callback que retorna true/false); `map()`, que devuelve un nuevo array transformando cada elemento; y `reduce()`, que reduce el array a un único valor acumulado (suma, objeto, cadena, etc.). El modelo mental clave es que estos métodos son inmutables: no modifican el array original, sino que devuelven uno nuevo. Esto favorece un código más legible y predecible. Ejemplo mínimo: const productos = [ { nombre: 'Teclado', precio: 25 }, { nombre: 'Monitor', precio: 200 } ]; const baratos = productos.filter(p => p.precio < 100); const nombres = productos.map(p => p.nombre); const total = productos.reduce((acc, p) => acc + p.precio, 0); Errores frecuentes: olvidar retornar un valor dentro del callback de `map` o `filter` (uso incorrecto de llaves sin `return`); confundir `filter` con `map` (uno selecciona, el otro transforma); olvidar el valor inicial en `reduce`, lo que provoca resultados inesperados; y modificar el array original creyendo que estos métodos lo alteran. Recuerda también que estos métodos se pueden encadenar: `productos.filter(...).map(...).reduce(...)`, leyéndose de izquierda a derecha como una tubería de transformación.
