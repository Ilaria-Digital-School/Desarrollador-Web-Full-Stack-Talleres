# Navegar por su carpeta de trabajo desde el terminal

Recordatorio teórico Navegar por el sistema de archivos mediante el terminal es una competencia fundamental para cualquier desarrollador. Permite controlar el ordenador con precisión y realizar tareas de automatización. Para ello, se utilizan comandos básicos: `pwd` muestra el directorio de trabajo actual (Present Working Directory), `ls` lista los contenidos de una carpeta, y `cd` cambia el directorio actual. La estructura de archivos es jerárquica, similar a un árbol invertido. Un concepto clave es la diferencia entre rutas absolutas (completa desde la raíz `/` o `C:\`) y rutas relativas (desde la ubicación actual). Los errores frecuentes incluyen olvidar la distinción entre mayúsculas y minúsculas en sistemas Unix, intentar cambiar a un directorio que no existe, y confundir el símbolo `~` (directorio personal) con `.` (directorio actual) o `..` (directorio padre). Un modelo mental sólido consiste en imaginar siempre dónde se está y adónde se quiere ir, utilizando los comandos como un mapa y una brújula. Como miniejemplo, desde su directorio personal, el comando `cd Proyectos` lo lleva a una subcarpeta, `ls` le mostraría, por ejemplo, 2 archivos y 3 carpetas, y `cd ..` lo devolvería al punto de partida. Enunciado del taller Este taller tiene como objetivo consolidar su habilidad para explorar su propio entorno de trabajo usando únicamente la línea de comandos. Deberá demostrar que comprende la estructura de su carpeta de proyectos, que sabe moverse a través de ella y que puede extraer información sobre su contenido.
