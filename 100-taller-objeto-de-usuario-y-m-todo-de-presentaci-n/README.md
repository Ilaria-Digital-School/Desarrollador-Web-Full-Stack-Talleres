# Taller: objeto de usuario y método de presentación

RECORDATORIO TEÓRICO Un objeto literal en JavaScript es una estructura que agrupa datos (propiedades) y comportamientos (métodos) bajo un mismo nombre. Se declara con llaves: const usuario = { nombre: 'Ana', edad: 30 }. Cada propiedad es un par clave-valor, y se accede a ellas con la notación de punto (usuario.nombre) o de corchetes (usuario['nombre']). Un método es simplemente una propiedad cuyo valor es una función. Dentro de un método, la palabra clave 'this' hace referencia al propio objeto que lo contiene, permitiendo acceder a sus otras propiedades. El modelo mental útil es imaginar el objeto como una ficha que describe una entidad del mundo real: un usuario tiene atributos (nombre, correo, edad) y sabe hacer cosas (presentarse, saludar). Un mini-ejemplo: const usuario = { nombre: 'Ana', edad: 30, presentarse() { return `Hola, soy ${this.nombre} y tengo ${this.edad} años.`; } }; console.log(usuario.presentarse()); Errores frecuentes: olvidar 'this' dentro del método (referenciando 'nombre' en lugar de 'this.nombre'), usar funciones flecha cuando se necesita el 'this' del objeto, confundir la coma que separa propiedades con el punto y coma, o intentar llamar al método sin los paréntesis (usuario.presentarse en lugar de usuario.presentarse()). Dominar estos fundamentos es esencial porque los objetos son la base de casi toda la manipulación de datos en el desarrollo web.
