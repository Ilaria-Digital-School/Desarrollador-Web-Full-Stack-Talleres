# Crear una galería de imágenes con Grid

Recordatorio teórico: fundamentos de CSS Grid CSS Grid Layout es un sistema de maquetación bidimensional diseñado para organizar elementos en filas y columnas de manera simultánea. A diferencia de Flexbox, que trabaja principalmente en una dimensión, Grid permite un control preciso sobre ambas dimensiones, creando una malla completa donde colocar los componentes. Un modelo mental útil es imaginar una cuadrícula invisible que divide el espacio contenedor en celdas. Usted define esta estructura mediante propiedades como grid-template-columns y grid-template-rows. Los elementos hijos se colocan dentro de esta matriz, pudiendo ocupar una o varias celdas adyacentes. Un error frecuente es confundir Grid con Flexbox y aplicar ambos sistemas simultáneamente sin necesidad, lo que complica el código. Otro error común es olvidar que, por defecto, los elementos se colocan automáticamente en la siguiente celda disponible. Esto se controla con grid-auto-flow. Un ejemplo mínimo: para un contenedor con 3 columnas de 200px y 2 filas de 150px, se usaría «grid-template-columns: 200px 200px 200px;» y «grid-template-rows: 150px 150px;». Esto crea una cuadrícula de 3x2 celdas donde cada imagen podría ocupar su celda. Preparación del entorno de trabajo Su primer objetivo es crear la base de archivos que sustentará la galería. Inicie configurando un proyecto claro y organizado, con una estructura de carpetas simple pero efectiva. Comience por establecer un archivo HTML válido y semántico. El contenido debe incluir un encabezado descriptivo, un área principal para la galería y un pie de página. Debe preparar un conjunto de imágenes de prueba de diferentes orientaciones y dimensiones,...
