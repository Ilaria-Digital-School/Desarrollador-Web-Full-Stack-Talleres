# Construir la maquetación de una página de inicio con Grid

Recordatorio teórico CSS Grid es un sistema de maquetación en dos dimensiones: organiza los elementos en filas y columnas a la vez. Flexbox, que usted ya ha practicado con la barra de navegación y las tarjetas, distribuye los elementos en una sola dirección. Grid sirve para la estructura general de la página y Flexbox para alinear el contenido dentro de cada bloque. El modelo mental es el de una cuadrícula dibujada sobre el contenedor. Con display: grid, sus hijos directos se convierten en elementos de la cuadrícula. La propiedad grid-template-columns define las pistas verticales y grid-template-rows las horizontales. La unidad fr reparte el espacio libre disponible. La propiedad grid-template-areas permite dibujar la página con nombres. Cada elemento se coloca después con grid-area. También puede colocar un elemento por números de línea, por ejemplo grid-column: 1 / 3. Recuerde que 3 columnas tienen 4 líneas. Mini-ejemplo: .page { display: grid; grid-template-columns: 1fr 1fr 1fr; grid-template-areas: "header header header" "hero hero hero" "footer footer footer"; } y después header { grid-area: header; }. Errores frecuentes: • Aplicar display: grid a un hijo en lugar del contenedor. • Escribir filas de grid-template-areas con un número distinto de celdas. • Dibujar áreas que no forman un rectángulo. • Usar en grid-area un nombre que no coincide con el de la plantilla. • Confundir líneas y pistas.
